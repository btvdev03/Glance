## Tính năng chính

- **Dịch chuột tức thì**: Bôi đen từ, câu hoặc đoạn văn để xem bản dịch ngay cạnh con trỏ chuột.
- **Smart Skip (Bỏ qua tiếng mẹ đẻ)**: Tự động nhận diện ngôn ngữ. Người Việt bôi đen tiếng Việt hoặc người nước ngoài bôi đen tiếng của họ sẽ không hiện popup làm phiền; tự bỏ qua số và ký hiệu.
- **Closed Shadow DOM**: Giao diện được cô lập hoàn toàn, không bị xung đột CSS hay vỡ bố cục trên bất kỳ trang web nào.
- **Từ điển & Phiên âm IPA**: Hiển thị từ loại (danh từ, động từ, tính từ), từ đồng nghĩa và phiên âm quốc tế.
- **Phát âm bản xứ**: Nghe phát âm chuẩn qua Web Speech API.
- **Thay thế tại chỗ (`Ctrl + Enter`)**: Dịch và thay thế trực tiếp đoạn văn bản đang chọn trong ô nhập liệu (email, tài liệu, chat).
- **100% Riêng tư & Miễn phí**: Không cần API Key, không theo dõi và không gửi dữ liệu người dùng ra ngoài.

## Cài đặt

Tương thích với **Google Chrome**, **Microsoft Edge**, **Brave**, **Cốc Cốc**, **Opera**.

1. Tải file [glance-extension.zip](glance-extension.zip) và giải nén.
2. Truy cập `chrome://extensions` trên trình duyệt và bật **Developer mode** (Chế độ nhà phát triển).
3. Bấm **Load unpacked** (Tải tiện ích đã giải nén) và chọn thư mục vừa giải nén.

## Phím tắt

| Phím tắt | Chức năng |
| :--- | :--- |
| `Esc` | Đóng thẻ dịch |
| `Ctrl + Enter` | Thay thế chữ gốc bằng bản dịch trong ô soạn thảo |
| `Ctrl + C` | Sao chép nhanh bản dịch |
| `Ctrl + Bôi đen` | Chỉ kích hoạt dịch khi giữ Ctrl (tùy chọn trong Cài đặt) |
| `Alt + Bôi đen` | Chỉ kích hoạt dịch khi giữ Alt (tùy chọn trong Cài đặt) |
